# vdakos.github.io

Source of the personal website of Vasilis Dakos (Institut des Sciences de l'Évolution de
Montpellier, CNRS), published at <https://vdakos.github.io/>.

The pages are generated by `scripts/build_site.py` in the private repository `vasilis_website`
from an export of the former WordPress site; edits to pages belong in that script. To update the
site: run the script, then `quarto render` in this folder, and commit the changes together with
`docs/`. GitHub Pages publishes the `docs/` folder of the `main` branch.
